# Іван Бойко — лендінг маркетолога

Статичний лендінг (HTML + CSS + vanilla JS, без залежностей), зібраний з Figma-макета `DRAFT / Section 3` (desktop 1920 + mobile 393).
Анімації відтворюють поведінку референсу marketinglab.framer.ai:

- навбар «падає» зверху (y −80 → 0, spring);
- секції з'являються при скролі (y 60 → 0, fade);
- абзац «Про мене» зафарбовується по літерах під час скролу;
- безкінечні стрічки ключових слів і логотипів клієнтів;
- картки «Мій підхід» — sticky-сходинка, що збирається в ряд;
- «Довіра клієнтів» — sticky-фон із заголовком, картки відгуків перевертаються при наведенні (тап на мобільному);
- кнопки: прокрутка тексту + заміна іконки-стрілки;
- послуги розкриваються при наведенні, перемикач тарифів, FAQ з табами та анімованим акордеоном.

Поважає `prefers-reduced-motion`.

## Запуск

```bash
python3 -m http.server 4317
```

і відкрити http://127.0.0.1:4317
